# MERN Social RBAC App

Monolithic, modular MERN social media application with RBAC, built as a pnpm workspace monorepo.

## Workspaces
- `apps/api` - Node.js + Express + TypeScript backend
- `apps/web` - React + TypeScript (Vite) frontend

1. Install dependencies once:
◦  `pnpm install`
2. Start backend API:
◦  `pnpm dev:api`
3. Start frontend web app:
◦  `pnpm dev:web`
